# App Store badge

`app-store-zh-cn-black.svg` is Apple's unmodified Simplified Chinese App Store download badge, retrieved on 2026-09-16.

- Source: https://toolbox.marketingtools.apple.com/api/v2/badges/download-on-the-app-store/black/zh-cn
- Usage guidelines: https://developer.apple.com/app-store/marketing/guidelines/

Keep the original artwork and aspect ratio. The Mac download is a separate website button because the Mac companion is distributed as a DMG, not through the Mac App Store.
