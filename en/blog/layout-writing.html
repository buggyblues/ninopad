Focus on text creation: use writing layout to follow your heartbeat, search within the text and typesetting with one click

Using the four-level range of words/words/sentences/paragraphs to accurately move the cursor, combined with in-text search and Markdown format panel, greatly reduce the burden of memorizing keyboard shortcuts.

September 10, 2026

When writing and polishing long articles, your hands don’t need to frequently leave the main keyboard to touch the mouse. The writing layout integrates paragraph jumps, in-text search, and commonly used Markdown title and style buttons on the secondary screen, allowing you to focus all your attention on the text itself.

Picture description:This time, the "paragraph" range, in-text search pop-up window and format desktop entrance were actually verified. The screenshot text and statistical values ​​use the demo state; text selection and formatting effects need to be confirmed in the real Mac editor.

Before starting

  • Install Naimao Control 1.2.0 on iPhone/iPad, and install the companion version of the same version on Mac; complete the pairing, and allow accessibility permissions on the Mac side. When you need the computer screen, turn on the screen recording permission.
  • Create a new exercise document in Mac "Text Edit" and write two paragraphs of text: "Write an outline today." "Add examples tomorrow." Put the cursor into the text. Please use Markdown proprietary operations in supported editors; precise integration of Obsidian requires the installation of supporting plug-ins.

1. Enter the writing layout and check the text statistics and cursor position.

Click the "Layouts" tab at the bottom of your iPhone, find and enter the "Writing" layout in the list. For multi-desktop solutions, please expand the arrow on the right and click the corresponding desktop.

After entering the writing desktop, the small screen can read back the text statistics and word count status fed back by the editor. Open a document you are writing on your Mac and use your mouse to position the cursor in the middle of a paragraph as a starting point for practice.

2. Switch the jump range to "segment" and test the jump at the beginning and end of the segment.

On the phone's "character/word/sentence/paragraph" range selection bar, tap to switch to the "paragraph" level. At this time, the boundary operation buttons at both ends will be automatically mapped to "Head of Paragraph" and "End of Paragraph".

Click "End of Paragraph" and observe whether the cursor on Mac jumps to the end of the current natural paragraph; click "Start of Paragraph" again and the cursor returns to the beginning of the paragraph. If you need fine-tuning of individual characters, just switch back to "Word" on the range bar.

3. Use the "Search" function to quickly locate keywords in the text

Click the "Search" button on your mobile phone to bring up the "Search within text" interactive pop-up window. Fill in the target keyword (such as "outline") in the input box and click "Search" in the pop-up window.

Click "Search" again to view or modify the query terms; use "End Search" to end this search. Canceling the pop-up window will not clear the memorized keywords, so check the old words in the input box first after changing the document.

4. Select key text and apply bold format

Select the word "Outline" on the Mac, and then press the "B" key (bold) on the writing desktop. In editors that support rich text, selected text immediately becomes bold; press it again or use the undo shortcut to restore it.

If the document is plain text, font styles may not be preserved. Don't infer from a button press that the editor must have completed a format change; confirm document mode and editor support first.

5. Switch to the "Format" desktop and convert the Markdown title level

Click the page switching button at the bottom right of the writing desktop to enter the dedicated "Format" desktop. Bold, italic, underline, hyperlink and "Text/H1...H6" title level control keys are aggregated here.

Markdown exercises can be done with a disposable Markdown file: place the cursor over a heading line, select H2, and examine the actual text or heading level in the editor. Text editors behave differently than Markdown editors, validating one format before continuing with other operations.

6. Return to the main writing desktop and stay focused on the editing rhythm

Click the return button in the lower right corner of the format desktop to switch back to the main writing desktop and continue to maintain the original range selection state. If you need to input directly, you can click "Keyboard" on the format desktop, and click "Finish" to return when finished.

The "Delete" key on the writing desktop supports long pressing to switch to continuous deletion mode. It is recommended to use a single click for the first time to ensure that every step of cursor displacement and format adjustment is under control.

FAQ

The mobile phone displays the word count, but why can’t I select the text of the web page accurately?

Statistics reading, text selection and modification are different abilities. Read-only web pages or areas without open text interface may not necessarily allow precise operations. Verify in the editable text first.

Markdown operations not responding in Obsidian?

Check the Obsidian directory in the companion integration package for installation instructions, whether the plugin is enabled, and whether it is currently in editable notes. First confirm that normal input is normal, and then verify proprietary commands such as titles and lists.
