3D modeling handheld assistant: from Blender perspective roaming to natural collaboration of quick operations

The dedicated keys are automatically switched with the front-end software, and combined with Blender's default key positions, it is easy to complete object selection, focus and viewport surround, and support horizontal screen two-hand control.

September 10, 2026

When creating 3D, your hands are often busy moving back and forth between shortcut keys and the mouse wheel. The application creation platform will dynamically transform according to the current front-end software: just tap in Blender to focus on objects, switch editing modes or surround the viewing angle, and hold it horizontally to enjoy efficient blind operations brought by ergonomics.

Picture description:The illustrations use the Blender sample working state, and the horizontal and vertical screens and editing portal are operated within the app. The modeling exercise is written based on the current adaptation mapping. Please confirm the effect item by item in your own Blender temporary scene.

Before starting

  • Install Naimao Control 1.2.0 on iPhone/iPad, and install the companion version of the same version on Mac; complete the pairing, and allow accessibility permissions on the Mac side. When you need the computer screen, turn on the screen recording permission.
  • Open Blender on your Mac, use the default shortcut configuration and a temporary scene, and place your mouse over the 3D view. Customized key positions, focus on the text box, and inputting transformation values ​​may all change the effect of shortcut keys.

1. Start Blender on Mac and enter the application creation platform

Launch Blender on your Mac and open a 3D practice project. Click "Layout" at the bottom of your iPhone, find and enter the "App Creation Station" layout in the list.

Observe the software status bar at the top of the phone to confirm that the foreground application has been accurately identified as "Blender", and the buttons below automatically appear as 3D view-specific controls such as "Focus Selected", "Select All", and "Deselect". "Desktop Objects.blend" in the screenshot is the name of the sample project and no additional download is required.

If the keys of other software are still displayed on the mobile phone, click the Blender window on the Mac to bring it to the foreground to automatically refresh the status to avoid accidentally touching keys under incorrect mapping.

2. Use all selection and deselection to verify the two-way linkage of the viewport

In Blender's 3D viewport, first click the "Select All" button on your phone to see if all objects in the Mac scene are highlighted; then click "Deselect" to confirm that the selection is completely cleared.

These two basic operations can help determine whether the focus accurately stays in the 3D viewport. If you were editing the text attribute box before, please exit the text input and move the mouse back to the 3D viewport before verifying.

3. Select the model mesh and test "focus selected" and perspective surround

Select an object directly in Blender, then click "Focus Selected" on your phone to check whether the view adjusts around the selected object. Then gently adjust the horizontal and vertical surround controls and observe the change in viewing angle.

Perspective changes are not the same as object transformations. Orbiting is the viewing direction; "Move", "Rotate" and "Scale" on the direction control will enter the object transformation operation and should not be mixed continuously without distinguishing them.

4. Switch to editing mode to safely perform modeling adjustments

After selecting the editable object, click the "Switch Mode" button to check the current mode of Blender; press it again to return. The same shortcut key may act on objects, vertices, or other elements when in different modes.

Complete the selection and pattern exercises before using delete or transform. If you need to cancel the ongoing Blender operation, first press Escape on your Mac to confirm that it has returned to a stable state.

5. Place the phone horizontally to experience the wide-width two-hand control engineering

Place the phone horizontally and the interface will automatically rearrange into a horizontal screen wide creation platform. Hold it naturally with both hands, re-confirm the positions of the main knobs and function keys, and enjoy an ergonomic and fast blind operation experience.

Horizontal screen adaptation only reorganizes the UI layout and does not change Blender's project status or mode settings. You can still view the current object and viewport rendering in real time on the Mac screen.

6. Enter desktop editing and freely customize the personalized creation table

Click "Layout → Edit Current Desktop" to freely adjust the position and mapping binding of existing components according to your personal workflow. It is recommended to note down the original functions before modification, and verify them by testing each button after completion.

When switching to editing, drawing or audio software, the sub-console will be reloaded according to the corresponding configuration. If there are differences in the shortcut keys of different versions of the software, you can refer to the README instructions in the integration package for targeted fine-tuning.

FAQ

The software is open but the controls are still unavailable?

First check the front-end application, editing context and supporting integration status. The control should be enabled only if the adapter provides the corresponding capabilities; functions not provided by the software cannot be obtained by forcing the button to light up.

My Blender operations are different from the tutorial?

Check default key bindings, 3D view focus, and object/edit mode before verifying the operation directly on your Mac. Imported custom presets retain their own bindings and are not guaranteed to be the same as the built-in schemes.
