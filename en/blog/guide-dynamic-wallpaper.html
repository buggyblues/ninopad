Change a moving wallpaper: from built-in animals to your own videos

Search for animals in Themes & Wallpapers, apply live wallpapers, adjust the display, and learn about multi-select import, save and layout individual settings.

September 11, 2026

If you want to give the commonly used layout a little more of your own look, you can change the wallpaper first. 1.3.0 has eight built-in animal dynamic wallpapers, and also supports saving your own photos, videos and animations. This article will first use the built-in capybara wallpaper, and then introduce how to add custom materials to the list.

Picture description:The pictures come from the wallpaper list, search and setting process of the native app. Static screenshots are used to illustrate the entrance and options; dynamic wallpapers are played in the App. This article does not use pictures to claim frame rate or power consumption performance.

Before starting

  • Updated to NinoPad Magic Control 1.3.0. Classic cream is free to use, illustrations and custom wallpapers require membership permissions.
  • Open "Settings" → "Themes & Wallpapers". What is modified here is the wallpaper in the app and will not change the iOS lock screen or system desktop.
  • Start with the built-in wallpapers, no video preparation required, and no need to connect to a Mac.

1. Open the change wallpaper list

After entering "Themes and Wallpapers", click on the current preview or "Change Wallpaper". The list starts with keeping the classic cream and adding custom wallpapers, followed by saved materials and built-in wallpapers.

Items marked "dynamic" can be played in the actual layout. The list uses a cover preview for quick browsing; don’t think that the video is invalid just because the thumbnails in the list are not moving.

2. Search for capybara and select Orange Soup Warm Day

Enter "capybara" in the search box and the list will be narrowed down to corresponding animal wallpapers. You can also directly search for the name "Orange Soup Warm Ri". The classic cream and added custom entries will still be retained, making it easy to change back or add materials at any time.

After clicking "Orange Soup Warm Day", return to the theme settings and check whether the name on the right side of "Change Wallpaper" has changed. Confirm that the name is consistent with the preview, and then return to the main layout to see the effect.

3. Adjust display mode and softening

After returning to the theme settings, you can choose to fill or display completely, and adjust the "soft wallpaper". First select the area of ​​the image you want to keep, and then adjust the softening to make the keys and text clearer.

There are also playback options for dynamic material; when you need to focus on playing or reduce the dynamic picture, you can choose to display only the cover. Switching wallpapers will retain the display settings, and the layout of wallpapers that have been set individually will not follow this global replacement.

4. Add your own photos or videos

Enter "Change Wallpaper" again and click "Add Custom Wallpaper". Select the import quality first, and then select materials from photos or files; the quality option only affects the next import and will not redo already saved wallpapers.

The photo portal allows you to select multiple images, videos, and Live Photos; the file portal allows you to select images, animations, and system-decodable videos. After selecting, wait for the processing to end, check the preview after seeing "Dynamic Wallpaper Selected", and then click "Use Wallpaper" in the upper right corner to save. Use the capybara video provided with the app to practice importing pictures, and the save button is ready to use.

5. Save to list and switch directly in the future

When selecting multiple materials at one time, clicking "Use Wallpaper" will add the successfully processed materials to the list and apply the last previewed one. There is no need to re-import next time, just select it directly in the wallpaper list.

Saved entries can be renamed or removed from the list with a long press. Canceling an edit will not save this unconfirmed import; removing a list entry will not delete media still used by the layout. Giving the material an easily searchable name will be more convenient than just remembering the import time.

6. Set a separate wallpaper for a layout

The global wallpaper is suitable for a unified appearance; if you only want another picture for the guitar or work layout, enter the layout's individual wallpaper settings from the theme settings, select the target layout, and then adjust. Before saving, check whether Apply to all layouts is checked.

When you need to bring the dynamic wallpaper to another device, first set up the target layout separately and then export it to the workbench. The layout that inherits the global wallpaper will not export the global application settings; the old version may only display the static cover when loading the new workbench.

FAQ

Why do dynamic wallpapers sometimes only display one picture?

In the background, low battery, weakened dynamic effects, high thermal status or memory pressure, the playback will be stopped and the cover will be retained. Also check that you have actively selected to only show covers.

Why did the Live Photo become a static image after importing it?

Select the full Live Photo from the photo library to read the paired video. Exporting JPEG or HEIC individually does not contain dynamic parts and requires reselecting the full Live Photo, or using the exported paired video.

Will the custom video sound play?

No. The wallpaper uses a silent loop, which does not superimpose the sound in the video onto the performance, recording or other playback content.

Is the clearer the video, the better?

Choose Energy Saving, Balanced or Clear by device and duration of use. When operating, playing or streaming for a long time, you can first select energy saving or cover only; over-limit or undecodable materials will be clearly prompted and will not be automatically truncated to pretend to be fully imported.
