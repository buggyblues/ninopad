Connect iPhone to Mac: Pairing & Permissions

Accessibility, screen recording and local network authorization troubleshooting, and local communication instructions on LAN · About 6 minutes to read

As a handheld secondary control and desktop streaming tool specially built for macOS, NinoPad needs to obtain the necessary auxiliary authorization from the system to achieve key mapping, shortcut command injection and desktop screen postback. After using the system for the first time or upgrading it, standardized permission configuration is the basis for ensuring the smooth operation of all functions.

This article will sort out the core system permissions, configuration operation procedures, common connection troubleshooting methods required by NinoPad, and the security architecture based on LAN point-to-point (P2P) direct connection.

1. Core system permission list and usage description

Start with the following permissions related to connections and desktop control. The project names of different macOS versions may be slightly different. Please operate according to the name actually displayed by the system; when other functions require additional permissions, the App will prompt you in the corresponding process.

  • Accessibility:Used to receive analog keys, wheel scrolling, combination shortcut keys and mouse cursor gesture control instructions sent by the mobile phone.
  • Screen Recording/Screen and System Audio Recording:Used to capture Mac real-time desktop frames and stream them to mobile phones in "Watch While Control" and "Full Screen Immersion" modes.
  • Local Network:Used to automatically discover Mac-side services through the Bonjour protocol within the same Wi-Fi or LAN and establish a high-speed point-to-point direct connection channel.

2. macOS permission configuration step-by-step guide

After launching the Mac companion for the first time, you can check control and screen permissions in System Settings. When you only need mouse and keyboard control, complete accessibility authorization first; when you need to view the screen, check the screen recording.

  1. Click the Apple icon  in the upper left corner of the Mac screen to openSystem Settings.
  2. Find and enter in the left sidebarPrivacy & Security.
  3. Click"Accessibility", find "NinoPad" (NinoPad) in the list, and switch the switch on the right side of it to allow.
  4. To return to the previous level, click"Screen Recording" or "Screen and System Audio Recording", make sure the "NinoPad" switch is turned on.

3. Common connection and permissions troubleshooting manual (FAQ)

1. Why does the connection timeout appear when scanning the QR code on the Mac with my mobile phone?

Please first make sure your iPhone/iPad and Mac are inUnder the same Wi-Fi router or LAN. If the router has "AP Isolation (Client Isolation)" turned on or is in "Guest Wi-Fi Mode", devices within the LAN will not be able to address each other. It is recommended to switch to the same standard home or office Wi-Fi network.

2. Why do the keys suddenly become invalid after a major version upgrade of the macOS system?

After the system is updated or the app is reinstalled, first check whether the authorization in the accessibility list is still enabled and whether it corresponds to the currently installed NinoPad. If you still cannot control it after opening it, you can try to remove the old entry and then add the current app; after reopening the companion terminal, use a mouse move or text input to confirm whether to restore it.

3. A black screen appears or permission prompt pops up repeatedly during desktop streaming?

Check the screen recording authorization first, then follow the system prompts to exit and reopen the Mac companion. Return to the phone and try again to preview the screen; if the screen is still black, confirm again that the authorization corresponds to the currently installed app and whether the connection between the phone and Mac is normal.

4. Local LAN point-to-point transmission and privacy instructions

The NinoPad team knows that the privacy of users' creations and projects is crucial, and ensures data security from the underlying architecture:

  • LAN direct connection:The desktop control flow here transmits keystrokes, text, and images through the connection between paired devices. Make sure you are connecting to your Mac before starting.
  • Understand the destination of data by function:Local direct connection describes the control connection between the mobile phone and the Mac. System voice recognition or other third-party services have their own processing methods, and it cannot be assumed that all functions do not require networking.
  • Pair management:Check the paired devices on the Mac companion terminal and confirm that the device list is consistent with your usage. Pairing information and home service tokens should only be used for your own device connections.
