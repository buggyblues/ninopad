Command line portable monitoring: create, switch and manage terminal sessions in full screen on your mobile phone

Manage Mac terminal session tags from the palm of your hand, run read-only commands to verify links, expand full-screen immersive input, and keep track of background compilation and operation and maintenance status at any time.

September 10, 2026

No need to keep a terminal window stacked in front of your home screen when compiling code or monitoring services. The terminal layout allows you to easily create and manage multiple Shell tabs on your mobile phone, receive terminal output in real time, and expand it to full screen to immerse yourself in input and browse history, making control of background tasks easier and more casual.

Picture description:This time, the new creation, renaming and full-screen operations are actually completed in the native terminal interface. The output in the screenshot is provided by Terminal Preview mode and is not a log of this remote command execution; the read-only commands below need to be run in your paired Mac session.

Before starting

  • Install Naimao Control on iPhone/iPad, and install the corresponding companion terminal on Mac; complete LAN pairing, and allow accessibility permissions on the Mac terminal. When you need the computer screen, turn on the screen recording permission.
  • The Mac companion needs to be running to support native shell sessions. When practicing, it is recommended to use a temporary session without important processes first, and do not close a session that is running time-consuming tasks.

1. Enter the terminal layout and get to know the session tab bar at the top

Click the "Layouts" tab at the bottom of your iPhone, find and enter the "Terminal" layout in the list. When there are many layouts, you can quickly search through the search box at the top.

Above the small screen are conversation tabs. The "Development" "Service" in the screenshot is from demo mode; when you first connect, you may not have any sessions yet. Don't think of these two names as configurations that must be created in advance.

2. Click the plus sign to create a new session and wait for the prompt to be ready.

Click the "+" button on the right side of the session bar and wait for the new terminal session label to be created and highlighted. The Mac side will allocate and start a new Shell instance simultaneously.

Wait for the terminal prompt (such as $ or %) to appear stably before proceeding, so as to avoid accumulating redundant empty sessions due to short-term network fluctuations and rapid clicking of the plus sign.

3. Open the terminal menu and rename the practice session to Build

Click on the "Terminal Menu" and select the "Rename" option. In the pop-up edit box, replace the default Shell 1 with the easily identifiable "Build" and click "Save" to confirm.

The top label will be updated to Build. This name is only used as a friendly label for mobile session management and will not change any local file directories on Mac or execute any background commands.

4. Expand the terminal in full screen and run the read-only command to verify the link.

Click the full-screen expansion button of the terminal component, and then click the keyboard icon in the full-screen interface. Enter the read-only check command into your phone's keyboard Ctrl And press Enter to view the current working path of your Mac.

Then enter top And press Enter, confirm that the next line is clearly echoed in the terminal output area. htop, verify that the two-way character transmission link is completely normal and has no garbled characters.

5. Switch the session label and confirm that the historical output is persisted

Put away the phone keyboard, click on other session tabs at the top to switch, and then switch back to the "Build" session to check whether the historical output of the command just executed is intact.

Click "Finish" in the upper right corner to exit full-screen mode. The terminal status in the small screen will still be synchronized in real time, and the background Shell process will not be interrupted abnormally when leaving the terminal layout.

6. Safely end the practice session and release system resources

After the exercise, if you do not need to keep the temporary session, first confirm that there are no time-consuming compilation or service processes running in the session, then open "Terminal Menu → Close Session" and click Confirm in the secondary confirmation panel.

At this point the Build tag is safely removed and the corresponding session on the Mac is properly cleaned up. If you just want to hide the keyboard temporarily, click Keyboard Hide or "Done" without closing the entire session.

FAQ

New button not available?

First check whether it prompts "Connect to Mac and then use Terminal" or "Please update Mac to use Terminal". Check the companion version and number of sessions if the connection is still unavailable; up to eight sessions per mobile device.

The text layout has changed after full screen. Did you open a new terminal?

No. Change the row and column dimensions of the terminal window to full screen and continue using the same session. Interactive command line programs may redraw to the new dimensions.

Can I still see the old output after the phone is disconnected?

Received content can continue to be read and copied; new commands require the connection to be restored. Exiting the Mac companion or actively closing the session will end the corresponding session.
