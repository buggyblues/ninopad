Precise organization and archiving: filter clips by type, package and export files with one click

Use keywords and media types to filter data multiple times, make multiple selections across conditions, and easily export text and attachments through the iOS native sharing panel.

September 10, 2026

As you have accumulated a lot of data, you don’t need to back it up in full every time. Filter by combining search terms with URLs, pictures, and other types, and check target items across conditions to export standardized and organized text and attachments through the system sharing panel, making data review and cross-software organization more refreshing and efficient.

Picture description:The accompanying picture shows the filtering, selection and system sharing panels of three local practice collections in the App. Which directory to save to finally needs to be selected on your own device.

Before starting

  • Open Clips from the Study Layout; the bulk Select entry is in the Clips list.
  • First create three practice collections: meeting list, source link check, and screenshot arrangement for next week. They are all tutorial material only.
  • This article demonstrates pure text export; items with existing attachments will bring out the original attachments at the same time, and you can preview the file before exporting.

1. Create three distinguishable exercise collections

Click "New Collection" one by one according to the following content and save it. In the second article, add the source title "NinoPad Study Tutorial" and the link https://ninopad.com/blog/layout-research in the "Source".

After saving, there should be three items in the list. The common keyword of the first two is "Friday review", and the third is only used to confirm that the screening has indeed excluded irrelevant content.

  • Meeting list: Text "Friday review: Organize meeting issues into a list."; Notes "Project Alpha, confirm the person in charge for the next meeting.".
  • Source check: Text "Friday Review: Update clipped source link."; fill in the above source title and link.
  • Next week's schedule: Text "Next week's schedule: Arrange screenshots on Tuesday."; note "Project Beta".

2. Combine search and content type, look for linked material first

Enter "Friday review" in the search box and confirm that only the first two are left. Click "Website" in the content type again, and you should only see the "Update Clip Source Link" item.

There are two levels of filtering here: "All/Collection/History" at the top determines the content range, and the content type determines the URL, image, file or text to be viewed; the search terms will continue to narrow the scope. This example entry with a source URL can be filtered by "Website".

3. Select the first item, then switch the filter to add the second item

Click "Select" in the upper right corner and check the source check item. Then switch the content type back to "All Types", keep the search terms, and check the meeting list. The bottom should say "Export(2)".

Switching filters will not clear selected items. This behavior is suitable for finding images first, then text, and exporting them together, but it also means that the number of entries seen on the current screen may be less than the actual number selected. Before clicking export, check it based on the bottom quantity.

4. Open the export and select the storage location in the system sharing panel.

Click "Export (2)" and wait for the system sharing panel to appear. To leave a file that can be inspected, select "Save to 'File'" or the synonymous option currently displayed by the system, then select a directory and complete the save.

The apps, languages, and system versions installed on different devices will affect the sharing panel options. When selecting a receiving app, the file receiving method it actually supports shall prevail; the screenshots in this article show the prepared export content and system panel.

5. Check the exported text, notes and sources

Go to the directory you just selected and open the exported .txt file. In this example, there should be two entries: one containing the meeting text and "Notes", and the other containing the source check text and the title and URL in "Source". File numbers are generated in the order of entries when exported, and do not have to be consistent with the order listed in this article.

If the entry also has attachments, the original attachments will be exported together as independent files; when the same underlying attachment is used by multiple entries, duplication will be removed, and suffixes will be added to distinguish files with the same name but different files. Therefore, "selecting two files" does not necessarily mean "exporting only two files".

6. Understand the scope of “select all” and avoid bringing out unnecessary content

In selection mode, "Select All" will select all items in the current filter results, including items that require scrolling to see. "Unselect all" will only cancel this batch of results, and the checked content under other filtering conditions will still be retained.

When the number of selections is not as expected, click "Cancel" in the upper left corner to exit the selection mode, clear the check box, and then select again. Exporting only generates a copy of the file and does not delete the original collection; after saving, open the file first and confirm that the required text, notes, sources, and attachments are all there.

FAQ

Why does the export quantity not return to zero after changing the filter conditions?

This is the behavior of cross-filter selections. Selected items will remain; check with the bottom number, or exit selection mode and select again.

Is the export a fully recoverable database backup?

What is exported is an easy-to-read .txt text file and the original attachment, suitable for archiving or sending to other software. It is not a full database backup that can be restored with one click.

Why can't I see batch "selects"?

Start by going to the "Clips" folder from the study layout and making sure there are entries. The history records in the keyboard are mainly used for backfill input, not the batch sorting entry demonstrated in this article.

Why are the number of exported files and the number of selections different?

Each piece of content may generate a text file with multiple attachments; duplicate attachments will be deduplicated. Check the entry text and attachment name first, don't just compare the quantity.
