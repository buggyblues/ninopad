Knowledge excerpt workflow: capture fragments of inspiration and archive the original text, personal notes and sources.

Seamlessly read Mac selections or manually enter data, add exclusive thoughts and source links to excerpts, and build a well-organized material library in your phone's clipboard.

September 10, 2026

Reading and research are not just copying words, but also a process of pondering. The research layout allows you to capture exciting selections on the screen at any time, jot down personal insights on your phone and retain complete sources, so that every piece of information collected can be valuable in the future.

Picture description:The selections and sources in the accompanying images are practice material. Adding new clips, filling in notes, saving and reopening are all done within the app; you can reproduce this process using the two sentences in the article.

Before starting

  • Install Nanny Control 1.2.0 on your iPhone/iPad to practice manual clipping. When you need to read Mac text selections, install the same version of the Mac companion, complete pairing and allow accessibility permissions.
  • If you don't have a Mac, you can start directly from step 2 of adding clips manually. To practice the original text, use "Tutorial practice: first ask questions, then check the original text." This sentence is an operation example and is not used as an external reference.

1. Select a piece of original text on Mac and then enter the survey

Select a small piece of text in a readable document or web page on your Mac and enter "Layout → Research" on your phone. Check whether the selection preview is consistent with what you just selected.

Check with short sentences first, don’t start with a full page screenshot. The source title and address will only appear if the system can read it; if the source is missing, manually check the original web page before saving.

2. Open the clipboard and add a new exercise text

Click "Clips" and then click the Add button. In the "Add text..." area, enter "Tutorial exercise: ask questions first, then check the original text." This is an operational exercise, not a citation from external literature.

The add page also provides album, file and paste entries. In this exercise, you only enter text. First, go through the saving and retrieval processes; then add attachments according to data type during formal collection.

3. Expand "Notes" and write down your own understanding

Click the "Notes" folded area and scroll down to find the input box if necessary. Fill in "My notes: cite after adding the source." and make sure it goes into the notes area and is not followed by the original text.

If there is an authentic source, click "Source" and fill in the source title and link. This exercise has no external source, so keep it empty; check the two paragraphs of text and click "Save" in the upper right corner.

4. Find the content you just saved in the list

After saving, go back to the Clip List and find the entry that begins with "Tutorial Exercises." If there are many entries, enter the keyword in the search box to check whether you can find it.

This step is more reliable than just seeing the "Save" button disappear: the actual appearance of the content in the list means that it has been entered into the current clipboard.

5. Open the details and check the original text and notes

Click on the exercise item to check the original text and note areas respectively. The original text should start with "Tutorial Exercises", and the notes should start with "My Notes"; check sentence by sentence whether you have retained what you just entered.

When corrections are needed, enter the edit page from the details page, modify the corresponding fields and then save. For formal materials, you should also check the source title, link and citation content, and do not fill in the author or source that does not exist based on a screenshot.

6. Replace manual exercises with real data

After mastering saving and retrieval, go back to Mac and select the real original text. First check the selection preview on the research desktop, then click "Take Notes" to add explanations and save. After each one is received, check the content and source in the clipboard before continuing to the next one.

When you need to return to the source or copy a citation, first confirm that the material actually stores available source information. Manual notes without sources can still be saved, but trusted external citations cannot be automatically generated from them.

FAQ

Why can't I click "Take Notes"?

First select readable text on Mac, and then check whether the selection on the phone is updated. This entry is unavailable when there is no valid selection; you can use manual addition in the clipboard instead.

Can I still organize my saved content without connecting to my Mac?

You can view, manually add and edit local content in your phone's clipboard. Reading the current Mac selection or returning to the Mac source requires corresponding connections and capabilities.

What should I do if the old version of Clips is missing?

History clippings of different versions are not automatically guaranteed to be migrated. Before upgrading, please export the content you want to keep from the old version; do not regard the empty list as migration completion.
