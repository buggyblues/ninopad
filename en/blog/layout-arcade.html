How to use your mobile phone as a controller to play the Magic Game Hall

Let you quickly get started with the Magic Game Hall. Use your paired mobile phone as a touch screen controller, choose your favorite party or single-player game, and start fun battles with friends on the same screen.

September 16, 2026

Want to play some relaxing party games with friends? Open the built-in game lobby on the Mac, pair your phone and enter "Games" in the bottom layout, which can be used as a touch screen controller to control direction and movement. Games such as "Breaking Sky" and "Paper Soccer" support multiple mobile phones to join. The main controller can pause or return to the lobby by clicking on the small screen menu, making it easier to play on the same screen at a party.

Picture description:Illustration showing the P1 controller, game menu, and landscape arrangement for a soccer example session. Real game response and multiple phones joining needs to be checked on the same paired Mac.

Before starting

  • Install Naimao Control on iPhone/iPad, and install the companion client on Mac; complete the pairing, and allow accessibility permissions on the Mac client. When you need the computer screen, turn on the screen recording permission.
  • You need to have the arcade game installed and running on your Mac. The number of people and input method are determined by game adaptation; setting more people will not automatically change the single-player game to a multi-player game.

1. Open the game lobby on Mac

Open NinoPad on Mac and directly enter the game lobby built into the client. You can browse supported party games such as "Breaking Sky" and "Paper Soccer" in the lobby, or you can try single-player projects first.

Go to Magic Game Hall。

2. Pair your phone and enter the game layout

Make sure your phone and Mac are paired successfully, tap "Layout" at the bottom of the phone app and switch to "Games." Confirm the player's seat according to the selected game, and the screen will automatically display the corresponding direction and action buttons.

After the phone and Mac are paired and switched to the game layout, select the game card in the Mac's built-in game lobby and start it. After confirming that the game screen appears on the Mac screen, check the player number displayed on the mobile phone and start playing with the touch screen controller.

3. Claim the player number and test the response of the cross keys and action keys

After the game is started, check the player identification (such as P1) on the top of the phone. The small screen in the middle will display the name and running status of the currently running game.

Gently push the left cross direction key to control the movement of the character, tap the A, B, X, Y action keys on the right to verify the response to operations such as jumping and attacking, and confirm that the handle has been correctly bound to the current player seat. The key mapping for different games is subject to the current game settings.

4. Tap the small LED screen in the middle to call up the main control management menu

During the game, tap the small LED screen in the middle of the phone. The master controller (P1) will see management operations such as "pause game", "return to game lobby" and "exit game".

When you need to pause, explicitly select "Pause Game" and confirm on your Mac screen that the game screen has stabilized. Calling out the menu itself does not mean that the game automatically pauses. When resuming play, just re-enter the menu and select continue.

5. Place the phone horizontally to experience the full-function shoulder key layout for both hands

Turn the phone sideways and check the location of the direction area, action keys and shoulder buttons. First release all the buttons, then change the holding method; do a slight direction input again to confirm the character's response.

The horizontal screen in the picture is the actual rotated App layout, not another game or another set of mapping.

6. Connect to the second device for two-player battle, and exit safely at the end

After the second phone is paired with the same Mac, check to see if it gets another player ID, and then test independent movement separately. When waiting is displayed, check the game player limit and seats first, and do not start a new game repeatedly.

When it is time to end the game, the P1 controller selects to return to the lobby or exit the game in the small screen menu on the mobile phone. After confirmation on the Mac, the current game can be ended.

FAQ

Another phone says "Waiting"?

The game may only have one player seat, or it may be full. Check the number of people the game supports and the current player list; changing the number of people settings will not add multiplayer logic to the game.

Ordinary players click on a small screen and have no main control menu?

Pause, return to lobby and exit are provided by the master. First confirm whether the mobile phone displays the main controller or the identity of other players.

Can I directly use this layout to control any native Mac game?

The functions of this touch screen controller are subject to the Magic Control Game Hall and adapted games, and are not equivalent to universal system controllers.
