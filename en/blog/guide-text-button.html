Turn high-frequency phrases into physical keys: touch them with your fingertips and input them to Mac with one click

Configure shortcut buttons for frequently used phrases on your mobile phone, set additional enter or keystrokes, and check text through built-in preview, so you can say goodbye to repeated typing on the keyboard.

September 10, 2026

Why bother tapping the keyboard repeatedly when replying to fixed phrases, frequently used addresses or customer service templates several times a day? Create an exclusive text button in NinoPad, stop the cursor in the Mac window, and input accurately with just one tap on your phone. Follow this exercise to create the first shortcut key for your commonly used "confirm receipt" button.

Picture description:The images are from the app's native editor and content preview, using sample text and simulated connections. Preview only shows content on your phone; actual input and synchronization must be confirmed on a connected Mac.

Before starting

  • Use Naimao Magic Control 1.2.0; enter the desktop with space to add buttons. This article starts with the work layout.
  • To actually use it on a computer, you need to connect to a computer running Naimao Magic Control for Mac, and follow the prompts to enable the required permissions for control.
  • First prepare a blank test document and place the cursor in the text to facilitate confirmation of the input position and the effect of additional keys.

1. Add a shortcut button and select "Send Text"

Click "Layout" at the bottom, then click "Edit Current Desktop." After entering the editor, click "Add Component" and select the "Button" component; new buttons need to be configured first.

Click "Send Text" in "Common Operations" in the operation list, and the editing page with the same name will open. If you are adjusting an existing button, go to its "Action" page, click "Replace" next to the current operation, and then select "Send Text". Complete the content settings first, then adjust the button appearance.

Reference:Illustration of the editing entrance of work layout。

2. Save a complete and usable reply first

Fill in the "Enter text to send" field with practice sentences. Check the punctuation and wording, and leave the specific date, amount, or name that needs to be modified each time for actual use to avoid mistaking a certain reply as a general template.

Scroll down to "Save Name" and change the name to "Confirm Received". This name is used to identify the automation content; the text on the button surface is adjusted in the "Name" of the component "Appearance", and both need to be checked separately.

3. Decide whether to add keys after input is completed

Open "After completing input" in the "After input" area, you can select "Don't append keys", "Press Enter", "Press ⌘Enter" or customize shortcut keys. For the first exercise, select "Don't add keys" to let the text stay in the current input box, leaving an opportunity for inspection and modification.

Enter has different meanings in different software: it may be a new line or it may be sent directly. Only after the behavior has been confirmed in the target software, the corresponding button will be added to this reply. Entering text will not automatically find the chat window, nor will it confirm the recipient for you.

4. Leave "Send once" and check with content preview

Leave "Send once" in "Send by". This example only has one text, no need to repeat rounds or hold down bursts. Click down on "Preview content" and check whether the sentence is fully displayed in the preview.

"Content Preview" only displays the content that will be taken out in this round. It will not operate the Mac, nor will it advance the progress of retrieving the official text list. You can click "Preview Next Round" to check again; seeing the text does not mean that the computer has received the text.

5. Save the configuration and verify it again in the Mac document

Close the content preview and return to the editing page. When an available automation service is connected, "Save and Sync" is displayed in the upper right corner; when not connected, "Save Draft" is displayed. Press the current button to save and watch if the page reports a sync failure or timeout.

Return to the component properties and click "Finish", then exit desktop editing. Now switch to the Mac test document, click the text to make the insertion cursor appear, and then click the new button on the phone. Only one reply should be inserted; there is no append key in this example and the text should remain in the document. If "To be synchronized" is still displayed, reconnect and open the edit page to save the synchronization and try again.

6. When multiple replies are needed, expand the text list

Go back to "Edit text and send method", click "Add one" to continue writing the second one; if you already have line-by-line text, you can use "Import by line...", and each non-blank line in the import preview will become an independent entry.

"Access method" will appear in multiple texts. "Next in order" is used to retrieve items one by one, "Random one" and "Get in order after shuffling" are suitable for rotating materials, and "Enter all at once" will retrieve the entire list. First use "Preview next round" to observe the selected method, and then decide whether to turn on "Return to the first after the last one". Don't confuse "which line to take" with "how many rounds to repeat" as one setting.

FAQ

Why doesn't the expected window appear after clicking the button?

Text input depends on the current input position of your Mac. First confirm that it has been synchronized, then switch to the editable text of the target software and click the cursor; when the menu, pop-up window or other window takes the focus, the input position will also change accordingly.

The save name has been changed, but why hasn’t the word on the button changed?

Saving a name is a text action. Go back to the "Appearance" page of the component properties to modify the button display text, and then exit the editor to check.

The preview is successful. Does this mean there is no problem with the connection?

No. Content preview is done locally. Mac execution requires additional verification of connection, sync status, permissions, and actual input results.
