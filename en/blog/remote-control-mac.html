Control Your Mac from iPhone or iPad: Four-Step Setup and Troubleshooting

Updated 2026-10-05 · 4 min read

NinoPad turns your iPhone or iPad into a trackpad, keyboard, and shortcut keypad for your Mac over a shared local network. Connect and verify cursor movement first, then enable screen mirroring when you need to view the Mac display.

Three Things to Check Before Connecting

  • Install Both Apps

    Get the mobile app and the free Mac companion.

  • Use the Same Network

    Connect both devices to regular Wi-Fi. Internet remote access is not supported.

  • Grant Permissions in Order

    Accessibility controls input; Screen Recording streams the display.

iOS / iPadOS 17+ · macOS 13+ · Apple Silicon / Intel

Connect in Four Steps and Test the Cursor

  1. Install both apps

    Install NinoPad from the App Store. On Mac, open the .dmg from official GitHub Releases, drag NinoPad into Applications, then launch it.

    Official downloads ↓

  2. Display the pairing code

    Connect both devices to the same Wi-Fi. Click the cat icon in the Mac menu bar to open the QR code window.

  3. Scan with your phone

    Open the mobile Devices view and choose QR code pairing, or select your Mac from nearby devices and enter its six-digit code.

  4. Grant access and test

    Follow the Mac prompts to grant Accessibility permission. Open a trackpad workspace on your phone, swipe and tap to test cursor response.

How do you know it worked?

If the Mac cursor follows your finger, input is working. If the screen preview is black, check Screen Recording permission instead of pairing again.

Input and Screen Viewing Use Separate Permissions

On Mac, open System Settings → Privacy & Security. On iPhone or iPad, find NinoPad in Settings and check the required permissions.

PermissionWhen Needed
Mac AccessibilityRequired for cursor navigation, mouse clicks, keyboard entry, and keyboard shortcuts.
Mac Screen RecordingRequired only to stream the Mac screen to your mobile device. Named Screen & System Audio Recording on some macOS versions.
Mobile Local NetworkRequired to discover the Mac and establish local network communication.
Mobile CameraRequired to scan the pairing QR code. Manual 6-digit code entry does not require camera access.
Verify input first

Trackpad and keypad features do not require Screen Recording. If macOS prompts you to restart the companion app, quit and reopen it for changes to take effect.

Using Trackpad, Shortcuts, and Screen Mirroring

Trackpad

Move with one finger, tap to click, and scroll with two fingers. Test while watching your Mac screen.

Text & Shortcuts

Click into the target Mac window before sending text. Start your custom keypad with two or three frequent shortcuts.

Screen Mirroring

Enable Screen Recording, then toggle screen sharing in the device tab. Verify input control and display streaming separately.

Troubleshooting by Symptom

Mac does not appear in device list
  • Verify the Mac companion app is active and mobile Local Network permission is enabled.
  • Scan the Mac QR code directly. Guest Wi-Fi and public networks may isolate devices; test on a regular home Wi-Fi network.
QR code pairing times out
  • Wake your Mac and reopen the QR code window from the running companion app.
  • Confirm the devices can reach one another on the local network. Enterprise policies may restrict device-to-device traffic.
Connected, but cursor and keys do not respond
  • Verify Accessibility permission is granted to the currently running companion application in Mac System Settings.
  • Restart the companion app if prompted, then test cursor movement, clicks, and a short test phrase in a blank document.
Control works, but the screen is black or frozen
  • Check that Mac Screen Recording permission is enabled and screen sharing is turned on in the mobile app.
  • Restart the Mac companion app, switch active windows on the Mac, and check if the mobile stream updates.
Text appears in the wrong window
  • Click the target document or input field on your Mac to place cursor focus.
  • Send a short test word to confirm active focus before transmitting longer text.
Connection drops intermittently
  • Check whether your Mac entered sleep mode, the companion app closed, or your Wi-Fi network changed.
  • Reconnect on the shared network. If drops persist, note your OS versions, app versions, and the exact step where failure occurs.

Start with Free Features Before Upgrading to Pro

The basic keypad, core system controls, and the Mac companion app are completely free. Pro unlocks advanced workspaces, dynamic wallpapers, and standalone instruments, as indicated in the app. Upgrading to Pro will not resolve local network or permission configuration issues.

Frequently Asked Questions

Can I control my Mac remotely over cellular data while away from home?

No. NinoPad operates over a direct local network connection. Both devices must be on the same local network; cloud relay and internet remote desktop are not supported.

Can the Mac use Ethernet while the phone is on Wi-Fi?

Yes, as long as the wired and wireless connections can reach each other on the same local network. If pairing fails initially, connect both devices to the same Wi-Fi to test.

Does trackpad and keypad control require Screen Recording permission?

No. Input control requires only Accessibility permission. Screen Recording is used exclusively when streaming the Mac display to your mobile device.

Does the iPad run Mac software locally?

No. All Mac software runs entirely on the Mac. The iPad only transmits input commands and displays the mirrored screen.
