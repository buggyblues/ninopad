Build a Custom Mac Shortcut Keypad on iPhone

Start with a preset layout and master grid size, operation binding, and appearance adjustments · Read about 6 minutes

NinoPad allows you to turn your idle iPhone or iPad into a handy Mac exclusive sub-console. Whether you need to quickly send frequently used copywriting, trigger high-frequency shortcut keys with one click, or adapt professional software through the "Application Creation Station", you can freely customize it through the visual desktop editor.

This article will take you starting from a basic preset and gradually master the complete process of entering editing mode, adding buttons, configuring width and height, binding specific actions, and adjusting appearance styles.

Tips for newbies:When using it for the first time, it is recommended to start with the built-in "work" or "launcher" and other preset layouts. After getting familiar with the basic interactions, you can add and delete buttons as needed.

1. Start exploring from the preset layout

NinoPad has built-in multiple scene presets covering daily office work, browser management, multimedia broadcast control, code development and design creation. In the "Layout" list at the bottom of the app, you can click directly to enter any plan to try.

2. Enter the current desktop editing mode

Click at the bottom of the app"Layout → Edit current desktop", enter the desktop editor. Select the component you want to adjust before modifying its position, appearance, or operation.

  • You can long press and drag the button to adjust its position in the grid;
  • point"Add component", select "Button", and configure the action for the new button.
  • Tap an existing button to open the appearance and property configuration panel.

3. Add buttons and set size width and height

NinoPad supports freely adjusting the grid size of each component. In the Dimensions area of the appearance settings:

  • Width adjustment:It supports 1 to 8 grid widths when held horizontally, and 1 to 4 grid widths when held vertically;
  • Height adjustment:Supports heights from 1 to 8 blocks.

Depending on how frequently the keys are pressed, you can set them as small, single-frame icons, or as wide, large keys and multi-line display panels.

4. Binding actions and shortcut commands

In the component action configuration panel, you can specify specific execution logic for the button:

  • Send text:Enter frequently used replies, customer service copy or frequently used code snippets, and set whether to append a carriage return after input;
  • System shortcut keys:Enter as ⌘C, ⌘V, ^Tab Single key or combination shortcut keys;
  • Launch the Mac App:Search and bind commonly used software installed on Mac to achieve one-click awakening;
  • Multi-step automation:Execute text input, delayed waiting and shortcut key combinations in series.

5. Adjust color, shape and icon appearance

To make the control panel clear at a glance, you can set rich visual styles for buttons:

  • Color:Choose an easily distinguishable color for your buttons. The launcher's app button can also use a "Follow App" color scheme.
  • Shape outline:Supports various contour switching such as rounded square, circle and rounded diamond;
  • Icon symbol:Choose functional symbols from the built-in icon library, or keep the display as text-only.

6. Save and try it on Mac

After you finish editing, click on the upper right corner"Done"Save configuration. Open the target document or software on your Mac and tap the keys on your phone to test the response.

When you need fine control over professional software, you can enter"Application Creation Station"——After identifying a supported foreground application, the creation platform will automatically switch to an exclusive operation panel for that software.

Before you connect

Can I control my Mac over the internet?

NinoPad controls a paired Mac over the same local network. It does not provide internet remote desktop or a cloud relay. Both devices need a reachable local Wi-Fi network; guest-network isolation can prevent pairing.

Which devices and systems do I need?

Use iOS / iPadOS 17 or later and the free Mac companion on macOS 13 or later, with Apple Silicon or Intel. Input control requires Accessibility permission; screen mirroring also requires Screen Recording permission.

What is free, and what does Pro unlock?

Basic keypad and system controls are free. Pro unlocks advanced decks, custom dynamic wallpapers and standalone instruments. Weekly, annual and lifetime plans provide the same Pro features; see the App Store checkout for local prices.
