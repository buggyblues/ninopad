Help & Support Center

Quick start guides, macOS system permissions troubleshooting, and answers to common questions

1. Local Network Pairing

  1. Ensure iPhone/iPad and Mac are connected to the same Wi-Fi network.
  2. Launch the Mac companion app to display the QR code in the menu bar.
  3. Open the mobile app, tap the scan button, and point your camera at the QR code.

2. macOS System Permissions

For smooth cross-application control and screen streaming, ensure the following permissions are granted:

  • Accessibility: Required for keystroke injection and trackpad cursor control.
  • Screen Recording: Required only if you use live desktop screen mirroring.
  • Local Network: Ensure iOS allows NinoPad to find local devices.

Frequently Asked Questions

Why is Mac not responding to key presses or cursor movements?

Please open Mac 'System Settings → Privacy & Security → Accessibility' and verify that NinoPad is checked. If it was already checked, uncheck and re-check it, then restart the Mac app.

Why does the screen stream show a black screen or prompt for permission?

Screen mirroring requires macOS 'Screen Recording' authorization. Check 'System Settings → Privacy & Security → Screen Recording' and ensure NinoPad has access.

How do I restore my Pro subscription on a new device?

In the iOS app, go to 'Settings → NinoPad Pro' and tap 'Restore Purchases'. Ensure your device is logged into the same Apple ID used for the initial purchase.

Which macOS versions and Mac hardware are supported?

Supports all Macs running macOS 13 (Ventura) or later. The Universal binary natively supports Apple Silicon (M1/M2/M3/M4) and Intel processors.
