Privacy Policy and Security Instructions

Last updated: October 1, 2026

1. Data processing principles

NinoPad uses a pure local area network communication architecture to connect iPhone/iPad and Mac. There is no need to register an account, no need to log in, and no cloud server is used to transfer your control commands or screen images.

2. Locally stored data

Your custom keypad layout, pairing credentials, connected device aliases, and app preferences are all securely saved in the device's local sandbox. The main app shares connection state with the iOS desktop widget through a protected App Group.

3. Purchase and Subscription Security

Pro membership purchases, renewals, automatic deductions, cancellations, and refunds are all handled by Apple’s official StoreKit channel. NinoPad only reads verified valid membership rights and will never contact or store any of your bank card information, billing address or Apple account credentials.

4. iCloud cloud synchronization

After you actively turn it on, the personalized keypad layout and settings will be synchronized across devices strictly through your personal Apple iCloud container; NinoPad will never use such data for any analysis or advertising purposes.

5. Local network communication and screen recording

The app discovers Mac devices on the same Wi-Fi LAN via Apple's native Bonjour protocol. Control commands are transmitted directly point-to-point; low-latency screen streaming only takes effect after obtaining macOS "Screen Recording" authorization and is only transmitted locally.

6. Instructions for using system permissions

The Mac side requires the "Accessibility" permission to execute cross-application shortcut keys and mouse commands; the "Screen Recording" and "Microphone" permissions are only requested on demand when screen streaming or wireless microphones are enabled, and you can revoke them at any time in the system settings.

7. Third-party services and analysis

The official website provides HTTPS secure static hosting and distribution of the entire site, and the installation package is securely distributed through GitHub Releases. There will never be any third-party advertising SDK or cross-application tracking code embedded in the NinoPad app.

8. Contact and feedback

If you have any questions about this privacy policy, please contact GitHub Issues Contact us.

9. Website analytics

The website loads Google Analytics 4 only after you allow it, to measure page visits, language, guide clicks, views of the Pro section and clicks on App Store or Mac download links. It uses first-party analytics cookies, and Google may receive network and device information when processing requests. We do not send pairing credentials, screen contents, clipboard contents, typed text, personal account identifiers or arbitrary URL query parameters. Website analytics is separate from the app’s local control data. Advertising personalization, Google signals and cross-app tracking are not enabled.

Decline or withdraw consent through Analytics preferences in the footer. Browser Do Not Track and Global Privacy Control signals prevent analytics from loading. App Store links use Apple’s public campaign identifiers; actual downloads and purchases are reported in App Store Connect. A download click is not recorded as a purchase.
