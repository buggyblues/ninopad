v1.3.0
September 11, 2026

Synthesizers, guitars and dynamic wallpapers give your phone more ways to play

Synthesizer: from a chord to an arrangement
  • Four new desktops have been added: Chord, Tone, Arrangement, and Loop. Play with the seventh-level chord keys and joystick, adjust the tone, and edit drum beats, chords, bass, and melodies.
  • The six-track loop supports recording, overdubbing, undoing, and mixing; projects can be saved, restored, and exported to WAV or MIDI.
  • Sound material can be exchanged with sample layouts; MIDI output is optional when connected to a Mac. The sound can be played on the mobile phone, and there is no need to pair the computer first for basic performance.
  • Improved audio peak protection, long project saving and recording ending, reducing unnecessary refreshes when switching interfaces.
Guitar: strum, change chords, and learn step by step
  • Two new desktops, Guitar and Learning, have been added. Six sensor strings, eight-way chord rocker, mute keys and bend strip can be combined and played.
  • The console supports editing chords, tunings, capos, voices and left- and right-handed orientations, saving your own solutions and listening to them before switching.
  • The learning desktop provides 100 harmony exercises, selected according to style and difficulty; listen to the demonstration first, and then practice step by step following the string positions and chord tips. The content is an independently arranged short exercise, not an original recording or complete score.
  • Improved anti-accidental touch, playback stop and background recovery during strumming, retaining clear operation feedback.
Live wallpapers and personalization
  • There are eight built-in animal dynamic wallpapers, which can be searched by name and can also be set individually for different layouts.
  • Custom wallpapers support importing images, videos and animations from photos or file multiple selections; Live Photo can read dynamic parts from the photo library.
  • The wallpaper list supports reuse, renaming and removal, and provides three levels of import quality: energy-saving, balanced, and clear, and the option to only display the cover.
  • Live wallpapers play silently and retain static covers in the background, low battery, or weakened dynamic effects. Videos of layouts used alone can be exported with the workbench.
The operating experience works with Mac
  • Improved presentation pointer position updating and drawing, optimized trackpad, continuous controls, and feedback on touch release.
  • Improved Mac MIDI message handling and muting behavior for synthesizers and guitars.
  • The official website page is organized into 17 sets of layouts according to purpose, supplemented with actual app screenshots and introductory tutorials of new functions.
Update method
  • iPhone/iPad updates via TestFlight; on Mac, check for updates in-app or download a new version of DMG.
  • It is recommended that mobile phones and Macs be updated to 1.3.0 together. The minimum system requirements are still iOS/iPadOS 17, macOS 13.
  • This Mac installation package follows the configuration of the previous version and does not include the system virtual controller that requires additional authorization; the in-app game lobby and MIDI can still be used.

15 preset layouts covering work, creation and daily life

15 preset layouts
  • Work, Launcher, Browser, Media, Presentation, Ambient Programming, Terminal, Writing, Research, Reading, Finance, Application Creation Bench, Sampling, Gaming and Smart Home. Some layouts contain multiple desktops with the ability to edit position, size, color, and motion.
new features
  • Terminal: Create a standalone shell on a paired Mac with session tabs, full screen, font size, and Chinese input, retaining up to 8 sessions per device.
  • Writing: Dual desktops for text and format, move and select by word, word, sentence, and paragraph; new title slider, Markdown format, search, and word count. Precision editing with Obsidian requires the installation of the included plug-in.
  • Scientific research and reading: classified collection of selected articles, notes and actual sources; PDF, EPUB and web page turning, scroll wheel, table of contents and chapter jump. See the official website guide for the capabilities and verification scope of different readers.
  • Finance: Numeric keypad, local calculator, 28 table shortcuts and four pages of 64 formulas. Click to enter the formula, long press to fill in the parameters; send text to the current application on Mac without reading the workbook or automatically submitting.
  • Smart home: The mobile phone is directly connected to the existing Home Assistant or Apple home, and the device capabilities are added to the editable layout; a Mac is not required, and the Matter device needs to be connected to the corresponding home platform first.
  • Launcher: Read Mac application icons and Dock order, support editing of multiple desktops and application buttons.
  • Unified clipboard: collection and input history, text/website/picture/file filtering, album multi-selection, batch export and keyboard draft recovery.
  • Presentation: The phone screen and camera can be transferred to the Mac presentation window to supplement the speech aid, page turning and timing desktop.
  • Sampling: local sound library, slicing and 16-frame performance combination, adding mobile phone and Mac sound collection entrance, improving recording, saving and exporting.
Improvements and fixes
  • The media layout unifies the information screen and click wheel navigation, and adds playback queue, progress positioning, sound output and timed pause; the menu is displayed according to the actual capabilities of the player.
  • The application creation platform expands software adaptation, organizes the core operations of clipping/CapCut, and improves numerical focus switching and continuous knob gesture recovery.
  • Preset text, desktop automation, action recording and hotkey triggering can be configured to layout keys.
  • Added wallpaper selection and layout appearance settings, improved layout browsing, native paging and button editing.
  • Fixed issues in browser input and URL copying, clip filtering, formula parameter group deletion, and recording and streaming status management.
Please note before updating
  • This Mac installation package does not include the virtual HID controller yet: Apple still needs to grant the corresponding Developer ID permission. Keyboard and mouse control and other functions are not subject to this restriction.
  • It is recommended that iOS and Mac be updated at the same time. iOS/iPadOS 17+, macOS 13+; Mac installation package includes Apple Silicon and Intel architecture.
  • The new clipboard uses a separate local database and does not automatically import old keyboard history or old excerpts. Please copy or export the old content that needs to be retained before upgrading.
  • Sampling local performances, calculators and home controls each have independent usage conditions; software adaptation, lyrics, document directories and device controls are subject to actual capabilities.
  • The Pro functions and prices within the app are subject to those shown on the purchase page. The demo data in the official website guide is only used to display the interface.
