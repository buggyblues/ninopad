从安装到连接，只需三步

无需复杂的网络配置，处于同一局域网 Wi-Fi 下一扫即连

STEP 01

安装 Mac 端

从官方 Releases 下载 DMG 镜像，将“奶猫妙控”拖入“应用程序”文件夹并启动运行。

STEP 02

开启系统权限

在“系统设置 → 隐私与安全性”中开启“辅助功能”权限；若需桌面画面预览再开启“屏幕录制”权限。

STEP 03

扫码一键连接

确保 iPhone/iPad 与 Mac 连接同一 Wi-Fi，打开移动端扫码即可秒速配对成功。

常见支持问题手册

解答关于网络连接、权限排查、会员订阅及隐私安全的常见疑问

在哪里下载 iPhone、iPad 和 Mac 正式版？

iPhone / iPad 请前往 App Store 下载奶猫妙控，无需 TestFlight。Mac 请下载配套端，将 App 拖入“应用程序”后打开。安装完成后，让两端连接同一局域网，再用手机 App 扫描 Mac 的配对二维码。

为什么手机扫描 Mac 上的二维码提示超时？

请首先确认手机与 Mac 处于同一个 Wi-Fi 网络（不要一个连 5G Wi-Fi 一个连访客 Wi-Fi），且路由器未开启“AP 隔离”功能。若网络正常仍无法连接，可在 Mac 菜单栏右键彻底退出后重新打开尝试。

macOS 系统升级后按键突然失灵怎么排查？

macOS 大版本更新后可能残留旧签名的辅助功能权限。请前往“系统设置 → 隐私与安全性 → 辅助功能”，选中“奶猫妙控”点击下方减号 - 删除，再点击加号 + 重新添加即可恢复正常。

为什么手机端看不到 Mac 桌面实时画面？

桌面画面实时预览需要单独授予“屏幕录制”权限。请在“系统设置 → 隐私与安全性 → 屏幕录制”中开启奶猫妙控。常规按键、旋钮和触控板不受此权限影响。

更换新手机或重装后如何恢复 Pro 会员？

在 iPhone 或 iPad 端进入“设置 → 奶猫妙控 Pro”，点击“恢复购买”即可。所有订阅与购买均由 Apple App Store 托管，只要登录同一个 Apple ID 即可无缝恢复，Mac 端无需二次购买。

操作数据与画面会被上传到云端吗？

绝不上传。所有的按键指令、文字输入内容与屏幕实时图像，100% 仅在本地局域网 Wi-Fi 内部点对点直连传输，官方服务器不中继也不存储任何操作数据，充分保障隐私与工程安全。

支持哪些 Mac 硬件与 macOS 系统版本？

支持运行 macOS 13 (Ventura) 及更高版本的所有 Mac 电脑，Universal 通用架构原生适配 Apple Silicon (M1/M2/M3/M4 系列芯片) 与 Intel 处理器。
