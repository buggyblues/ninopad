Privacy

隐私政策与安全说明

最近更新日期：2026 年 8 月 31 日

1. 数据处理原则

奶猫妙控采用纯本地局域网通信架构连接 iPhone / iPad 与 Mac。无需注册账户、无需登录，亦不使用任何云端服务器中转你的控制指令或屏幕画面。

2. 本地存储的数据

你的自定义小键盘布局、配对凭据、已连接设备别名及应用偏好设置均安全保存在设备本地沙盒中。主应用与 iOS 桌面小组件通过受保护的 App Group 共享连接状态。

3. 购买与订阅安全

Pro 会员的购买、续订、自动扣款、取消与退款全部由 Apple 官方 StoreKit 渠道处理。奶猫妙控仅读取验证后的有效会员权益，绝不接触或存储你的任何银行卡信息、账单地址或 Apple 账户凭证。

4. iCloud 云端同步

经由你主动开启后，个性化小键盘布局与设置将严格通过你个人的 Apple iCloud 容器在跨设备间同步；奶猫妙控绝不会将此类数据用于任何分析或广告用途。

5. 本地网络通信与屏幕录制

应用通过 Apple 原生 Bonjour 协议发现同一 Wi-Fi 局域网内的 Mac 设备。控制指令点对点直连传输；低延迟屏幕串流仅在获得 macOS“屏幕录制”授权后生效，并仅在本地传输。

6. 系统权限使用说明

Mac 端需借助“辅助功能”权限执行跨应用快捷键与鼠标指令；“屏幕录制”与“麦克风”权限仅在启用屏幕串流或无线麦克风时按需申请，你可随时在系统设置中撤销。

7. 第三方服务与分析

官网提供全站 HTTPS 安全静态托管与分发，安装包通过 GitHub Releases 进行安全分发。奶猫妙控应用内绝不嵌入任何第三方广告 SDK 或跨应用追踪代码。

8. 联系与反馈

如对本隐私政策有任何疑问，欢迎通过 GitHub Issues 与我们联系。
